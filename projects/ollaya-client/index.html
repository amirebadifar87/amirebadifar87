مسئله

اتصال یک برنامه دات‌نت به API تصمیم‌گیری محلی، به مدل‌های درخواست و پاسخ روشن و جریان ناهمگام قابل استفاده نیاز دارد تا توسعه‌دهنده درگیر جزئیات سطح پایین سرویس نشود.

قابلیت‌های اصلی

  • API ناهمگام و سازگار با الگوهای دات‌نت
  • سؤال‌سازهای fluent و پاسخ‌های نوع‌دار
  • مدیریت مدل‌های محلی
  • ادغام با Dependency Injection
  • پشتیبانی از preset و مدل‌های vision
  • رفتار keep-alive قابل تنظیم

مسئله محصول و طراحی راه‌حل
